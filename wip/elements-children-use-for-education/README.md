# Leyenda
- Elemento sin marca: Posible opción a usar
- Elemento con +: Muy útil, se debería usar
- Elemento con -: Opción posible, pero se debería evitar su uso
- Elemento encerrado en recuadro/círculo verde: Elemento que se usará en el diseño preliminar
- Múltiples elementos encerrados en un mismo recuadro/círculo verde: Elementos que pueden usarse en el diseño preliminar cumpliendo un mismo propósito, por lo que se debería elegir uno de ellos o justificar el uso de varios, a modo de evitar duplicidades innecesarias
